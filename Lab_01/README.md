# Лабораторна робота №1. Основи функціонального програмування у Python

## Варіант 5. Бронювання готелю

Обробка бізнес-логіки готелю реалізована у функціональному стилі: без мутацій вхідних даних, без глобального стану та без I/O у розрахунковому ядрі. Усі обчислення базуються на чистих функціях (pure functions) та параметризації правил через Callable.

## Чисте ядро (core.py)

- Типізація: Booking та Report описані через TypedDict. Для політик (фільтр, знижка, збір) використано типи Callable.
- Чисті функції: base_cost (базова вартість), is_confirmed (перевірка статусу), calc_booking (створює новий об'єкт через розпакування словника {**booking}), make_report (формує підсумковий звіт).
- Фабрики політик: seasonal_discount (знижка за сезоном), long_stay_discount (за довге проживання), combine_discounts (композиція знижок через reduce), flat_fee та percent_fee (варіанти розрахунку туристичного збору).
- Функція вищого порядку: make_processor повертає налаштований обробник, що приймає конкретні політики (accept, discount, fee) і повертає функцію для обробки колекції бронювань.

## Оболонка ефектів (app.py)

- Демонстраційні дані: список словників SAMPLE із тестовими бронюваннями.
- Налаштування політик: фільтр min_nights(2), комбінована знижка (сезонна + за довге проживання) та фіксований туристичний збір залежно від типу номера.
- Вивід: результати роботи ядра передаються у функцію render_report, де відбувається форматування рядків та вивід у консоль (єдине місце з I/O).

## Висновок про незмінність
Переваги: розділення чистого ядра та побічних ефектів дозволяє тестувати логіку ізольовано. Завдяки використанню Callable політики (знижки, збори, фільтри) є взаємозамінними, що робить код гнучким до змін бізнес-вимог без переписування базових алгоритмів. Відсутність мутацій гарантує референтну прозорість і передбачуваність результатів.

Тестування: набір pytest-тестів перевіряє референтну прозорість (однаковий вхід -> однаковий вихід), відсутність мутацій (вхідні дані не змінюються, перевіряється через deepcopy) та коректність роботи переданих Callable-політик.
