# Завдання. Лабораторна робота №5 — Ліниві обчислення: генератори та itertools
Варіант 5. Рухоме середнє температур: потік температурних вимірювань; обчислити `moving_average` для вікон `k` та знайти перші значення, що перевищують поріг. Обов'язкові інструменти: `sliding_window`, `map`/`starmap`, `dropwhile`/`takewhile`.

# Вимоги

* Реалізувати власні генератори (`yield`, `yield from`), `take`, `drop`, `sliding_window`.
* Використати не менше трьох засобів `itertools` (`islice`, `accumulate`, `count`, `takewhile`, `dropwhile`).
* Не матеріалізувати нескінченні або великі потоки.
* Тест лінивості, крайні випадки (порожнє джерело, `n=0`, `k` більше за довжину, некоректний розмір вікна).
* pytest-тести, типи, black/ruff/mypy без зауважень.

# Критерії оцінювання
Коректність, лінивість і пам'ять, використання `itertools`, стиль і тестування.
