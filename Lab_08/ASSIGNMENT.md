# Завдання. Лабораторна робота №8 — Алгебраїчні типи даних "по-Python'івськи"

Варіант 5. Команди графічного редактора: `Move`, `Rotate`, `Scale`, `Delete`. Інтерпретувати послідовність команд над незмінним станом об'єкта. `Literal["move", "rotate", "scale", "delete"]`, `match/case` для кожної команди.

# Вимоги

* Описати ADT через `@dataclass(frozen=True)` та `Union`/`TypeAlias`.
* Використати щонайменше один `Literal`.
* Описати щонайменше один структурний контракт через `typing.Protocol`.
* Основну логіку реалізувати чистими функціями та `match/case`.
* Щонайменше дві операції над ADT (виконання команд, render, статистика).
* Вкладені/рекурсивні структури хоча б в одному тесті.
* pytest-тести для ADT, складних структур і помилкових/граничних випадків.
* `mypy --strict` без помилок.
* README.md з описом моделі та командами запуску.
* Вузли незмінні; функції повертають нові значення.
